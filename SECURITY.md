# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability (such as a sandbox escape in systemd units, a directory traversal in MCP server configurations, or credential exposure):

1. **Do NOT open a public GitHub issue.**
2. Report via private GitHub Security Advisory or contact `umairmsm@users.noreply.github.com`.
3. Please provide a clear reproduction path without transmitting real credentials.
