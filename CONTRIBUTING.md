# Contributing to second-brain-kit

Thank you for contributing! We welcome contributions that improve multi-agent collaboration, documentation schemas, and assistant security.

## Ground Rules
- Be constructive and collaborative. All interactions follow our [Code of Conduct](CODE_OF_CONDUCT.md).
- **No AI-generated spam PRs**: Changes must be tested and solve concrete engineering problems.
- **Sign Your Commits**: Sign commits using `git commit -s` (Developer Certificate of Origin).

## Pull Request Guidelines
- Keep pull requests atomic (<150 lines of diff where possible).
- Use Conventional Commits (`feat:`, `fix:`, `docs:`).
- Verify Python scripts with `python3 -m py_compile`.
